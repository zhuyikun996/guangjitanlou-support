适用范围与联系

本政策说明光迹探楼 iOS 应用 1.0.0 及 1.1.0 版本的数据处理方式，以及本支持网站和客服邮箱的相关处理。光迹探楼开发者为朱毅坤，隐私联系邮箱为 zusk66@gmail.com。

应用内的数据处理

应用无需注册或登录。我们不通过应用收集或上传个人信息，不接入广告、行为分析或第三方追踪 SDK，不出售个人信息，也不进行跨应用追踪。日照分析使用随应用提供的楼盘模型，在设备上计算，不使用你的实时位置。

本地选择记录

应用使用 iOS 的本地偏好设置保存你选中的楼栋、分段、楼层和节气日期，以便下次继续使用。这些选择不会由我们发送到服务器。它们会在你更改选择时更新。删除应用（不是仅卸载以保留数据）通常会移除其本地数据；设备备份和恢复行为由 Apple 及你的系统设置控制。

分享与剪贴板

仅当你主动使用系统分享面板并选择目标应用或接收方时，分析摘要及应用链接才会交给你选择的服务处理。摘要可能包含楼盘、楼栋、楼层、参考日期和估算结果。若你主动点击“复制官方图纸来源链接”，应用会把该链接写入系统剪贴板；应用不读取剪贴板中的其他内容。后续分享服务的数据处理以其政策为准。

外部链接与本网站

点击隐私政策、支持页面或官方图纸来源链接会打开系统浏览器。外部网站可能按其政策处理 IP 地址等访问信息。本隐私政策与支持网站由 GitHub Pages 托管，我们没有在页面中加入统计脚本、广告、表单、追踪 cookie 或第三方字体。GitHub 可能为提供和保护托管服务处理访问日志（包括 IP 地址），具体见 GitHub 隐私声明：GitHub Privacy Statement 。应用核心日照功能不依赖这些网页。

客服邮件

如果你主动发送客服邮件，我们会处理你提供的邮箱地址、邮件内容以及你主动附上的截图或其他资料，用于回复和解决问题。邮件由 Gmail 提供服务；请不要发送密码、验证码或与问题无关的敏感信息。客服资料仅在回复、解决问题及履行法律义务所需的期间保留；不再需要时删除或去除可识别信息。你可以通过客服邮箱提出访问、更正或删除请求，我们会核实请求并在适用法律要求的期限内处理。

系统服务与权限

应用不请求定位、通讯录、相机、麦克风或照片库访问权限。Apple 的设备备份、系统诊断和你选择的分享服务由相应提供方及系统设置控制；我们不将其用于应用内用户追踪。

未成年人

应用不专门面向儿童，也不通过应用收集儿童个人信息。如果你认为客服邮件中包含不应保留的未成年人信息，请通过上述邮箱联系处理。

政策更新

当应用功能或数据处理方式发生变化时，我们会更新本页面的日期与内容，并在必要时通过应用说明或更新信息告知。

未收录楼盘反馈

当你主动反馈未收录楼盘时，应用创建发送至客服邮箱的邮件草稿，内容包括你在搜索框输入的楼盘名称。只有你确认发送后才会发出，应用不会自动登记或上传该内容。未配置系统邮件时，可打开邮件应用或主动复制邮箱及反馈内容。
